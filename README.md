# Air Quality Monitoring and AQI Prediction System

## Overview
This project is an IoT-based Air Quality Monitoring and AQI Prediction System developed using ESP32, Embedded C, sensors, and MATLAB.

The system collects real-time air quality data from sensors, processes the readings using the ESP32 microcontroller, and performs AQI analysis and prediction using MATLAB.

---

## Features
- Real-time air quality monitoring
- AQI prediction and analysis
- Sensor interfacing with ESP32
- Data visualization using MATLAB
- Embedded C programming
- Pollution trend analysis

---

## Technologies Used
- Embedded C
- ESP32
- MATLAB
- IoT
- Sensors
- Data Analysis

---

## Components Used
- ESP32
- MQ135 Gas Sensor
- Breadboard
- Jumper Wires
- Power Supply

---

## Working Principle
The gas sensor collects air quality data and sends the readings to the ESP32 microcontroller. The sensor values are processed and analyzed to determine air quality conditions. MATLAB is used for AQI prediction, visualization, and pollution data analysis.
